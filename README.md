# Discord Mailer Bot System (Self-Bot)

Профессиональная система рассылки сообщений в Discord через обычные аккаунты (селф-боты) с ротацией токенов, сбором участников и автоматическим перефразированием текста через нейросеть (Gemini API) для обхода спам-фильтров.

## ⚠️ Внимание! Дисклеймер
Использование селф-ботов (автоматизация обычных аккаунтов пользователей) нарушает Условия использования (ToS) Discord. Это может привести к блокировке ваших аккаунтов. Настоятельно рекомендуется:
1. Использовать только второстепенные/покупные аккаунты (аккаунты-расходники).
2. Настраивать большие задержки между действиями (минимум 120-300 секунд).
3. Использовать ИИ для уникализации текста каждого отправляемого сообщения.
4. Ограничить количество рассылаемых заявок с одного аккаунта в день (не более 20-30 заявок в сутки на аккаунт).

---

## 🛠️ Особенности системы
1. **База данных SQLite**: Все собранные пользователи и токены хранятся в локальной базе данных. Процесс рассылки никогда не начнется заново — база данных запоминает, кому заявка отправлена, кто ее принял и кому ЛС уже доставлено.
2. **Параллельная ротация токенов**: Вы можете запустить рассылку сразу с нескольких аккаунтов. Они будут работать одновременно и распределять между собой список пользователей для отправки заявок.
3. **Обход спам-фильтров через ИИ**: Перед отправкой сообщения ИИ (Gemini API) слегка перефразирует ваш текст, делая каждое сообщение уникальным для каждого пользователя, при этом строго сохраняя ваши ссылки и ключевые данные.
4. **Умный сбор участников (Парсер)**: Позволяет собирать список участников с серверов по инвайт-ссылке или ID, автоматически отфильтровывая Администраторов и Модераторов (чтобы не привлекать лишнего внимания к рассылке).
5. **Интерактивное консольное меню**: Управление всей системой из простого и понятного интерфейса.

## 🚀 Установка и запуск

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python версии 3.10 или выше.
Установите необходимые библиотеки (они уже установлены в вашей системе):
```bash
pip install discord.py-self google-generativeai
```

### 2. Подготовка и запуск программы
Перейдите в папку проекта и запустите интерактивное меню:
```bash
cd discord_sender
python main.py
```

## 📖 Пошаговое руководство по использованию

### Шаг 1. Настройка параметров
1. В главном меню выберите пункт `[5] Настройки`.
2. Введите ваш **Gemini API Key** (если вы хотите использовать авто-перефразирование текста ИИ). Если ключа нет, система будет рассылать оригинальный текст без изменений.
3. Введите **Базовый текст сообщения** (включая ссылки или контакты).
4. Настройте задержки (рекомендуется оставить значения по умолчанию для снижения риска банов).

### Шаг 2. Добавление аккаунтов (токенов)
1. Выберите пункт `[2] Управление токенами`.
2. Вы можете ввести токен вручную или создать файл `tokens.txt` в папке проекта, вписать туда ваши юзер-токены (каждый с новой строки) и загрузить их все одной кнопкой.

### Шаг 3. Сбор пользователей с серверов (Парсинг)
1. Выберите пункт `[3] Спарсить участников сервера`.
2. Выберите аккаунт, с помощью которого будет происходить сбор.
3. Введите ссылку-приглашение на сервер (например, `https://discord.gg/invite_code`) или ID сервера (если аккаунт уже находится там).
4. Бот зайдет на сервер (если его там нет) и скачает весь список участников, автоматически отсеяв администраторов и модераторов, после чего сохранит обычных пользователей в базу данных.

### Шаг 4. Запуск рассылки
1. Выберите пункт `[4] Запустить автоматическую рассылку`.
2. Система запустит все ваши активные токены.
3. Каждый аккаунт будет с указанной задержкой (например, раз в 2-5 минут) отправлять запросы в друзья пользователям из базы данных.
4. Как только пользователь принимает запрос в друзья, бот мгновенно (или с небольшой человекоподобной задержкой) генерирует уникальный вариант вашего текста через Gemini ИИ и отправляет ему в личные сообщения.
5. Вы можете прервать рассылку кнопкой `Ctrl+C` в любой момент и запустить снова позже — база данных продолжит работу ровно с того места, где вы остановились.

## 📂 Структура проекта
* `main.py` — Главный файл управления и интерфейса.
* `database.py` — Управление SQLite базой данных (`sender_data.db`).
* `scraper.py` — Скрипт парсинга участников серверов.
* `sender.py` — Логика рассылки, ведения диалогов и ротации аккаунтов.
* `paraphraser.py` — Интеграция с нейросетью Google Gemini.
* `config.json` — Настройки (задержки, API-ключ, текст сообщения).
