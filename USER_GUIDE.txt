РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ - DISCORD MAILER (STEALTH EDITION)

Это руководство поможет вам настроить и запустить систему для максимально эффективной и безопасной рассылки сообщений.

1. ПОДГОТОВКА СИСТЕМЫ
Перед запуском убедитесь, что у вас установлен Python 3.10+ и необходимые библиотеки.
Команда для установки зависимостей:
pip install discord.py-self g4f google-generativeai aiohttp curl_cffi

2. ПЕРВЫЙ ЗАПУСК И НАСТРОЙКА (main.py)
Запустите программу командой: python main.py
Перейдите в пункт [5] Настройки:
- Текст сообщения: Ваше базовое сообщение (рекомендуется использовать ссылки и ключевые слова).
- Движок ИИ: Выберите 'free' (бесплатно через g4f) или 'gemini' (требуется API ключ).
- Задержки: Установите реалистичные интервалы.
  * Рекомендуется: 600-1200 сек для заявок в друзья, 120-300 сек для сообщений.

3. ДОБАВЛЕНИЕ АККАУНТОВ И ПРОКСИ [2]
Это критический этап для вашей безопасности.
- Ручной ввод: Введите токен, затем прокси в формате http://user:pass@ip:port.
- Импорт из файла: Создайте файл tokens.txt. Вписывайте каждый аккаунт с новой строки в формате:
  ТОКЕН|http://логин:пароль@ip:port
  (Например: ODU1MjM0...|http://admin:12345@45.12.34.56:8080)

4. СБОР УЧАСТНИКОВ (ПАРСИНГ) [3]
Чтобы собрать базу пользователей:
- Выберите один из ваших активных аккаунтов.
- Введите инвайт-ссылку на сервер или ID сервера.
- Программа начнет "невидимый" поиск. Она подпишется на каналы и пройдется по всей клавиатуре (буквы, цифры, символы), чтобы найти КАЖДОГО участника.
* Ограничений на количество участников нет.

5. ЗАПУСК РАССЫЛКИ [4]
После того как база собрана и токены добавлены, выбирайте пункт [4].
Процесс автоматизирован:
- Аккаунт заходит в сеть, ставит случайный статус (DayZ, YouTube и т.д.).
- Начинает отправлять заявки в друзья с учетом задержек.
- Как только заявка принята, бот имитирует "набор текста" (typing) и отправляет уникальное сообщение, перефразированное ИИ с добавлением невидимых символов (ZWS) для обхода фильтров.
- Вы увидите подробные [DEBUG] логи каждого действия.

6. ТЕСТИРОВАНИЕ [6]
Если вы хотите проверить работу на конкретных пользователях, используйте пункт [6], чтобы выбрать ID из базы и отправить сообщения только им.

СОВЕТЫ RED TEAM:
- Не используйте более 20 заявок в сутки на один аккаунт.
- Используйте индивидуальные прокси для каждого токена.
- Если аккаунт получает "Rate Limit", программа сама поставит его на паузу.
- Файл RED_TEAM_REPORT.txt содержит технические детали защитных механизмов.

Ваша рассылка теперь защищена лучшими методами обхода обнаружения. Пользуйтесь с умом.
