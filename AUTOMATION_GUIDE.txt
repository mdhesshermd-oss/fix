ИНСТРУКЦИЯ ПО GUI-АВТОМАТИЗАЦИИ И ОБХОДУ КАПЧИ

Эта система использует визуальное управление мышью (PyAutoGUI) для имитации действий человека при появлении капчи в Discord.

1. ТРЕБОВАНИЯ К СИСТЕМЕ
- Операционная система: Windows (рекомендуется) или macOS.
- Установленный Python 3.10+.
- Библиотеки: pip install pyautogui opencv-python pillow

2. ПОДГОТОВКА ЭКРАНА
- Discord должен быть запущен в полноэкранном режиме или в окне, которое ВСЕГДА находится на переднем плане.
- Отключите масштабирование экрана в Windows (установите 100%), иначе координаты мыши будут неверными.
- Сделайте скриншот иконки капчи (маленький значок, который появляется при проверке) и сохраните его как 'captcha_icon.png' в папке с ботом. Это нужно для автоматического поиска окна.

3. ПРИНЦИП РАБОТЫ (mass_sender.py)
Запускайте рассылку через файл: python mass_sender.py
- Бот отправляет сообщения через API.
- Каждые 10 секунд модуль automation.py сканирует ваш экран.
- Если на экране появляется окно капчи, бот:
  1. Перехватывает управление мышью.
  2. Имитирует человеческое движение (плавное перемещение по кривой).
  3. Делает клик в зону подтверждения "Я человек".
  4. Ждет 5 минут, пока Discord обновит сессию.

4. МЕРЫ ПРЕДОСТОРОЖНОСТИ
- FAILSAFE: Если бот "взбесился", резко уведите мышь в ЛЮБОЙ угол экрана. Это мгновенно остановит выполнение всех скриптов автоматизации.
- Не трогайте мышь и клавиатуру во время работы mass_sender.py, так как это может сбить алгоритм перемещения.

5. ТОНКАЯ НАСТРОЙКА
В файле automation.py вы можете изменить координаты клика в функции solve_interaction() под ваше разрешение экрана:
- target_x = screen_width // 2 (центр по ширине)
- target_y = screen_height // 2 (центр по высоте)

Система обучена имитировать "дрожание" руки и паузы перед кликом, что делает ее невидимой для большинства простых систем поведенческого анализа.
